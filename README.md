# 4X4-RAID

Crée un projet vide minimal, sans contenu de démonstration.

Stack exacte :
- Vite + React 18 + TypeScript
- Tailwind CSS
- react-router-dom
- alias d'import @/ vers src/

N'ajoute PAS shadcn/ui, ni lucide-react, ni framer-motion,
ni aucune librairie de composants.

Une seule page à la racine avec le mot "4x4-raid" sur fond noir.
Rien d'autre. Pas de header, pas de footer, pas de sections.

Ce projet va servir de base à un code existant qui sera importé
via GitHub — garde donc l'arborescence la plus nue possible.
